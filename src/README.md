# Earlier acquisition and classification pipeline

These scripts support the original multi-country study and Portuguese source-data construction. Imports and the root `data/`, `output/`, and `config/` locations are preserved.

Use **`analysis/`** for the current paper. Re-running these older scripts may require the 61 GB local source archive, network services, and dependencies beyond `requirements.txt`. They are supplied for provenance and further research, not as a claim that every historic download can be reconstructed.

The old report/bundle writers now use `archive/research-notes/` and `archive/drafts/`. The old 200-record validation sampler writes to `archive/validation-pilot-200/`. The current 800/2,000-record sheets and scorer are in `validation/` and `analysis/score_validation.py`.
